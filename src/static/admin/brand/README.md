# Assets de marca do Beautyflow

Este diretório recebe os arquivos oficiais de identidade visual sem exigir mudanças nos templates.

- `logo.svg`: logo principal neutra, usada como fallback.
- `logo-dark.svg`: logo escura para superfícies claras.
- `logo-light.svg`: logo clara para superfícies escuras.
- `favicon.svg`: favicon oficial.

O painel detecta cada arquivo antes de renderizá-lo. Enquanto os assets oficiais não estiverem presentes, a interface usa somente o nome “Beautyflow” em texto e não faz requisições para arquivos inexistentes.
